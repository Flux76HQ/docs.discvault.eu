## Procedimiento

1. **Elige:** FQDN · fuera de la excepción de localhost, las passkeys requieren un nombre de dominio completo estable mediante HTTPS de confianza; no se admite una IP sin nombre ni HTTP simple
2. **Elige:** [Instalación: Legacy Authentication](/es/install/legacy-authentication/) · para una IP privada o de bucle directa sin FQDN deja vacíos `RP_ID` y `RP_ORIGINS`
3. **Configura:** `RP_ID`
4. **Configura:** `RP_ORIGINS` · HTTPS
5. **Configura:** [Configuración: Inicio de sesión con OpenID Connect (OIDC)](/es/configure/oidc/) · `/api/next/auth/oidc/callback`
6. **Configura:** `6080` `6180`
7. **Prueba:** `GET /api/next/health`
8. **Registra:** elige el nombre de host antes de registrar passkeys; cambiarlo después exige registrarlas de nuevo, mientras localhost sigue siendo solo una excepción de configuración local

### Comandos y ajustes

#### DiscVault v26 estable

```text
RP_ID=discvault.example.com
RP_NAME=DiscVault
RP_ORIGINS=https://discvault.example.com
curl --fail https://discvault.example.com/api/next/health
```

#### DiscVault v26 beta

```text
RP_ID=discvault.example.com
RP_NAME=DiscVault
RP_ORIGINS=https://discvault.example.com
LEGACY_AUTH_ENABLED=true
curl --fail http://localhost:6180/api/next/health
```
