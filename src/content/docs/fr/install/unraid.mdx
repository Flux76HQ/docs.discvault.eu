## Objectif et résultat

Installez DiscVault depuis la boutique Community Applications d’Unraid. Le modèle installe le lanceur DiscVault, qui crée et met à jour pour vous PostgreSQL, l’API, le worker et MCP.

Suivez le déroulement propre à cette page pour **Installation: Unraid**. Cette procédure utilise `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## S’applique à

Helmer’s Repository propose DiscVault et DiscVault (beta) sous forme de deux modèles, chacun avec ses dossiers appdata, son port, son projet Compose et son réseau, pour fonctionner côte à côte.

Cette page s’applique uniquement à **Installation: Unraid** (Unraid). Les limites de canal et de données sont : DiscVault · `ghcr.io/helmerznl/discvault-launcher:latest`; `6080` · `/mnt/user/appdata/discvault` · `discvault_stack`; DiscVault · `ghcr.io/helmerznl/discvault-launcher:beta`; `6081` · `/mnt/user/appdata/discvault-beta` · `discvault_beta_stack`. Points de contrôle propres à la page : `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## Prérequis

- Unraid `6.12+`
- plugin Community Applications installé
- les passkeys exigent une adresse HTTPS avec un nom de domaine devant le port de l’app ; sans elle, utilisez la connexion par mot de passe avec TOTP

## Procédure

1. **Ouvrir:** Apps → recherchez DiscVault → Installer ; le modèle bêta porte (beta) dans son nom
2. **Configurer:** conservez les dossiers appdata par défaut ; le dossier du lanceur contient le fichier Compose généré et les secrets dans `/config/stack.env` · `TZ`
3. **Configurer:** `RP_ID` · `RP_ORIGINS` · les passkeys exigent une adresse HTTPS avec un nom de domaine devant le port de l’app ; sans elle, utilisez la connexion par mot de passe avec TOTP · `LEGACY_AUTH_ENABLED=true`
4. **Démarrer:** le premier démarrage prend quelques minutes, le temps que le lanceur récupère les images et crée la base · le lanceur monte le socket Docker et contrôle donc Docker sur le serveur ; installez-le uniquement si vous faites confiance à son image
5. **Vérifier:** `/api/next/health` · l’accueil crée le premier propriétaire avec une passkey, ou avec un mot de passe et TOTP, et affiche une seule fois les codes de récupération
6. **Configurer:** onglet Docker → Rechercher des mises à jour ; au démarrage, le lanceur met aussi à jour le reste de la pile · `DISCVAULT_CHANNEL=manual` · `DISCVAULT_IMAGE`

Le lanceur a récupéré les images et créé la pile, l’interface web répond sur le port du modèle et l’adresse de santé signale une base migrée.

## Sécurité et retour arrière

:::caution
Arrêtez l’app avant de copier ses trois dossiers appdata. Pour revenir en arrière, passez le canal en manual avec le tag de la version précédente et restaurez la sauvegarde faite avant la mise à jour.

La limite de récupération sûre pour **Installation: Unraid** impose ces actions avant tout démarrage ou toute poursuite : la bêta peut modifier la base de données d’une façon illisible pour l’app stable ; ne la pointez jamais vers les dossiers de la version stable; le lanceur monte le socket Docker et contrôle donc Docker sur le serveur ; installez-le uniquement si vous faites confiance à son image; la sauvegarde intégrée (Administration → Backup, aussi planifiée) déplace une bibliothèque entre Docker, Unraid et Home Assistant; le lanceur ne transmet pas encore les variables OpenID Connect ; le modèle Unraid se connecte donc avec des passkeys ou un mot de passe.
