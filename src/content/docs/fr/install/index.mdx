## Procédure

1. **Choisir:** [Installation: Docker Compose](/fr/install/docker-compose/) · DiscVault `main` `release/v26-beta`
2. **Choisir:** [Installation: Docker run](/fr/install/docker-run/)
3. **Choisir:** [Installation: Unraid](/fr/install/unraid/) · Unraid DiscVault
4. **Choisir:** [Installation: Home Assistant](/fr/install/home-assistant/) · PostgreSQL 17
5. **Choisir:** les nouvelles installations utilisent DiscVault `:latest` ou `:beta` ; l’image figée `:legacy` est réservée à une installation existante de la génération précédente qui n’est pas encore prête à migrer
6. **Conserver:** conservez les volumes, variables d’environnement, ports et chemin de données de la génération précédente ; ne remplacez jamais une image de la topologie Compose DiscVault PostgreSQL par `:legacy`
7. **Ouvrir:** [Mise à jour et migration: Migration vers DiscVault](/fr/update/migration/) · → DiscVault
8. **Consigner:** `DISCVAULT_IMAGE` · uniquement pour un déploiement existant ou legacy : jeu de sauvegardes correspondant
