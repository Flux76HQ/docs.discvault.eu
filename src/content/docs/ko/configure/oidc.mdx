## 적용 대상

이 페이지의 적용 범위: **구성: OpenID Connect(OIDC) 로그인** (Docker · 웹). 채널 및 데이터 경계: DiscVault · `26.9.117+`; OIDC는 선택적 브라우저 로그인 방법을 추가하며 로컬 패스키, 선택적 비밀번호, 복구 코드, API 토큰 및 MCP bearer 토큰의 기존 역할은 유지됨; ID는 issuer와 subject의 정확한 쌍이며 이메일로 자동 연결되지 않고 연결에는 로그인된 브라우저 세션이, 연결 해제에는 다른 사용 가능한 로그인 방법이 필요함. 이 페이지의 전용 확인 지점: OIDC · `/api/next/auth/oidc/callback` · `DISCVAULT_OIDC_ISSUER` · `DISCVAULT_OIDC_CLIENT_ID` · `DISCVAULT_OIDC_CLIENT_SECRET` · `DISCVAULT_OIDC_PROVIDER_NAME` · `DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS` · Pocket ID · PKCE · JWKS · `auth.oidc_failed`.

## 사전 요구 사항

- 소유자 접근 권한 · 두 번째 복구 방법
- [설치: 리버스 프록시 및 패스키](/ko/install/reverse-proxy-passkeys/) · localhost 설정 예외를 제외하면 패스키에는 신뢰할 수 있는 HTTPS의 안정적인 정규화된 도메인 이름이 필요하며, IP 주소만 사용하거나 일반 HTTP를 사용하는 것은 지원되지 않음
- ID 공급자의 기밀 OIDC 클라이언트와 정확한 DiscVault 콜백 URI

### 공급자 비공개 백 채널

:::note[베타에서 사용 가능]
정확한 비공개 HTTP 오리진은 토큰 및 JWKS 엔드포인트에만 허용하며 issuer와 브라우저 권한 부여는 HTTPS 전용이고 TLS 검증은 유지되며 discovery, 토큰 및 JWKS 리디렉션은 거부됨
:::

## 절차

1. **생성:** ID 공급자의 기밀 OIDC 클라이언트와 정확한 DiscVault 콜백 URI · `openid profile email` · `https://discvault.example.com/api/next/auth/oidc/callback`
2. **구성:** `DISCVAULT_OIDC_ISSUER` · `DISCVAULT_OIDC_CLIENT_ID` · `DISCVAULT_OIDC_CLIENT_SECRET` · issuer, 클라이언트 ID, 클라이언트 암호를 모두 함께 설정하거나 세 값을 모두 비워 두며 일부만 설정하면 시작되지 않음
3. **구성:** `DISCVAULT_OIDC_PROVIDER_NAME` · `OIDC`
4. **선택:** `DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS` · `localhost` · Kubernetes DNS · `.internal` · 정확한 비공개 HTTP 오리진은 토큰 및 JWKS 엔드포인트에만 허용하며 issuer와 브라우저 권한 부여는 HTTPS 전용이고 TLS 검증은 유지되며 discovery, 토큰 및 JWKS 리디렉션은 거부됨
5. **시작:** `next-api` · `--force-recreate`
6. **테스트:** OIDC는 선택적 브라우저 로그인 방법을 추가하며 로컬 패스키, 선택적 비밀번호, 복구 코드, API 토큰 및 MCP bearer 토큰의 기존 역할은 유지됨 · ID는 issuer와 subject의 정확한 쌍이며 이메일로 자동 연결되지 않고 연결에는 로그인된 브라우저 세션이, 연결 해제에는 다른 사용 가능한 로그인 방법이 필요함
7. **검사:** `auth.oidc_failed` · 실패 시 설정된 공급자 표시 이름, 안전한 `auth.oidc_failed` 코드 및 흐름 모드만 기록되며 암호, 토큰, 권한 부여 코드, state, nonce, 엔드포인트 URL 및 PKCE 값은 기록되지 않음

### 명령 및 설정

#### DiscVault v26 베타

```text
RP_ORIGINS=https://discvault.example.com
DISCVAULT_OIDC_ISSUER=https://id.example.com
DISCVAULT_OIDC_CLIENT_ID=<client-id>
DISCVAULT_OIDC_CLIENT_SECRET=<client-secret>
DISCVAULT_OIDC_PROVIDER_NAME=Pocket ID
DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS=
```
