## 목표 및 결과

Unraid Community Applications 스토어에서 DiscVault를 설치합니다. 템플릿은 DiscVault 런처를 설치하며, 런처가 PostgreSQL, API, 워커, MCP를 만들고 업데이트합니다.

이 페이지 전용 절차를 수행합니다: **설치: Unraid**. 이 절차에서 다루는 항목: `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## 적용 대상

Helmer’s Repository는 DiscVault와 DiscVault (beta) 두 템플릿을 제공하며, 각각 고유한 appdata 폴더, 포트, Compose 프로젝트, 네트워크를 가져 나란히 실행됨.

이 페이지의 적용 범위: **설치: Unraid** (Unraid). 채널 및 데이터 경계: DiscVault · `ghcr.io/helmerznl/discvault-launcher:latest`; `6080` · `/mnt/user/appdata/discvault` · `discvault_stack`; DiscVault · `ghcr.io/helmerznl/discvault-launcher:beta`; `6081` · `/mnt/user/appdata/discvault-beta` · `discvault_beta_stack`. 이 페이지의 전용 확인 지점: `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## 사전 요구 사항

- Unraid `6.12+`
- Community Applications 플러그인 설치됨
- 패스키에는 앱 포트 앞에 도메인 이름이 있는 HTTPS 주소가 필요하며, 없으면 TOTP와 함께 비밀번호 로그인을 사용함

## 절차

1. **열기:** Apps → DiscVault 검색 → 설치. 베타 템플릿 이름에는 (beta)가 붙음
2. **구성:** 기본 appdata 폴더를 유지하며, 런처 폴더에는 생성된 Compose 파일과 `/config/stack.env`의 비밀 값이 들어 있음 · `TZ`
3. **구성:** `RP_ID` · `RP_ORIGINS` · 패스키에는 앱 포트 앞에 도메인 이름이 있는 HTTPS 주소가 필요하며, 없으면 TOTP와 함께 비밀번호 로그인을 사용함 · `LEGACY_AUTH_ENABLED=true`
4. **시작:** 첫 시작은 런처가 이미지를 받고 데이터베이스를 만드는 동안 몇 분 걸림 · 런처는 Docker 소켓을 마운트하므로 서버의 Docker를 제어하며, 런처 이미지를 신뢰할 때만 설치함
5. **확인:** `/api/next/health` · 온보딩에서 패스키 또는 비밀번호와 TOTP로 첫 소유자를 만들고 복구 코드를 한 번 표시함
6. **구성:** Docker 탭 → 업데이트 확인. 시작할 때 런처가 스택의 나머지도 업데이트함 · `DISCVAULT_CHANNEL=manual` · `DISCVAULT_IMAGE`

## 안전 및 롤백

:::caution
세 appdata 폴더를 복사하기 전에 앱을 중지합니다. 되돌리려면 릴리스 채널을 manual로 바꾸고 이전 버전 태그를 지정한 뒤 업데이트 전 백업을 복원합니다.

안전한 복구 경계: **설치: Unraid** 시작하거나 계속하기 전에 다음 작업이 필요합니다: 베타는 안정판이 읽을 수 없게 데이터베이스를 바꿀 수 있으므로 안정판 폴더를 절대 지정하지 않음; 런처는 Docker 소켓을 마운트하므로 서버의 Docker를 제어하며, 런처 이미지를 신뢰할 때만 설치함; 앱 내 백업(관리 → Backup, 예약 가능)으로 라이브러리를 Docker, Unraid, Home Assistant 사이에서 옮김; 런처가 아직 OpenID Connect 변수를 전달하지 않으므로 Unraid 템플릿은 패스키 또는 비밀번호로 로그인함. 이 페이지의 전용 확인 지점: `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

- 베타는 안정판이 읽을 수 없게 데이터베이스를 바꿀 수 있으므로 안정판 폴더를 절대 지정하지 않음
- 런처는 Docker 소켓을 마운트하므로 서버의 Docker를 제어하며, 런처 이미지를 신뢰할 때만 설치함
- 앱 내 백업(관리 → Backup, 예약 가능)으로 라이브러리를 Docker, Unraid, Home Assistant 사이에서 옮김
- 런처가 아직 OpenID Connect 변수를 전달하지 않으므로 Unraid 템플릿은 패스키 또는 비밀번호로 로그인함
:::
