## Procedur

1. **Skapa:** en konfidentiell OIDC-klient hos identitetsleverantören med exakt DiscVault-callback-URI · `openid profile email` · `https://discvault.example.com/api/next/auth/oidc/callback`
2. **Konfigurera:** `DISCVAULT_OIDC_ISSUER` · `DISCVAULT_OIDC_CLIENT_ID` · `DISCVAULT_OIDC_CLIENT_SECRET` · ange utfärdare, klient-ID och klienthemlighet tillsammans eller lämna alla tre tomma; en ofullständig konfiguration förhindrar start
3. **Konfigurera:** `DISCVAULT_OIDC_PROVIDER_NAME` · `OIDC`
4. **Välj:** `DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS` · `localhost` · Kubernetes DNS · `.internal` · tillåt exakta privata HTTP-origins endast för token- och JWKS-endpoints; utfärdaren och webbläsarauktorisering förblir HTTPS-only, TLS-verifiering är fortsatt aktiv och omdirigeringar för discovery, token och JWKS nekas
5. **Starta:** `next-api` · `--force-recreate`
6. **Testa:** OIDC lägger till en valfri webbläsarinloggning; lokala passkeys, valfria lösenord, återställningskoder, API-token och MCP bearer-token behåller sina roller · en identitet är det exakta paret issuer och subject; e-post länkas aldrig automatiskt, länkning kräver den inloggade webbläsarsessionen och bortkoppling kräver en annan användbar inloggningsmetod
7. **Kontrollera:** `auth.oidc_failed` · fel registrerar bara leverantörens konfigurerade visningsnamn, en säker `auth.oidc_failed`-kod och flödesläge; hemligheter, token, auktoriseringskoder, state, nonce, endpoint-URL:er och PKCE-värden loggas aldrig

### Kommandon och inställningar

#### Båda kanalerna

```text
RP_ORIGINS=https://discvault.example.com
DISCVAULT_OIDC_ISSUER=https://id.example.com
DISCVAULT_OIDC_CLIENT_ID=<client-id>
DISCVAULT_OIDC_CLIENT_SECRET=<client-secret>
DISCVAULT_OIDC_PROVIDER_NAME=Pocket ID
DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS=
```

```text
DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS=http://pocket-id.pocket-id.svc.cluster.local:1411
```

```bash
cd /opt/discvault-next
docker compose -p discvault_next_deploy config --quiet
docker compose -p discvault_next_deploy up -d --force-recreate next-api
curl --fail https://discvault.example.com/api/next/auth/status
```
