## Mål och resultat

Installera DiscVault från Unraids Community Applications. Mallen installerar DiscVault-startprogrammet, som skapar och uppdaterar PostgreSQL, API, worker och MCP åt dig.

Följ det sidspecifika arbetsflödet för **Installation: Unraid**. Den här proceduren använder `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## Gäller för

Helmer’s Repository erbjuder DiscVault och DiscVault (beta) som två mallar med egna appdata-mappar, port, Compose-projekt och nätverk, så att båda kan köras sida vid sida.

Den här sidan gäller endast **Installation: Unraid** (Unraid). Kanal- och datagränserna är: DiscVault · `ghcr.io/helmerznl/discvault-launcher:latest`; `6080` · `/mnt/user/appdata/discvault` · `discvault_stack`; DiscVault · `ghcr.io/helmerznl/discvault-launcher:beta`; `6081` · `/mnt/user/appdata/discvault-beta` · `discvault_beta_stack`. ## Förutsättningar

- Unraid `6.12+`
- insticksprogrammet Community Applications installerat
- passkeys kräver en HTTPS-adress med domännamn framför appens port; utan en sådan används lösenordsinloggning med TOTP

## Procedur

1. **Öppna:** Apps → sök efter DiscVault → Installera; betamallen har (beta) i namnet
2. **Konfigurera:** behåll standardmapparna i appdata; startprogrammets mapp innehåller den genererade Compose-filen och hemligheterna i `/config/stack.env` · `TZ`
3. **Konfigurera:** `RP_ID` · `RP_ORIGINS` · passkeys kräver en HTTPS-adress med domännamn framför appens port; utan en sådan används lösenordsinloggning med TOTP · `LEGACY_AUTH_ENABLED=true`
4. **Starta:** första starten tar några minuter medan startprogrammet hämtar avbildningarna och skapar databasen · startprogrammet monterar Docker-socketen och styr därmed Docker på servern; installera det bara om du litar på dess avbildning
5. **Verifiera:** `/api/next/health` · introduktionen skapar den första ägaren med passkey, eller med lösenord och TOTP, och visar återställningskoderna en gång
6. **Konfigurera:** fliken Docker → Sök efter uppdateringar; vid start uppdaterar startprogrammet även resten av stacken · `DISCVAULT_CHANNEL=manual` · `DISCVAULT_IMAGE`

## Säkerhet och återställning

:::caution
Stoppa appen innan du kopierar dess tre appdata-mappar. Rulla tillbaka genom att sätta releasekanalen till manual med föregående versionstagg och återställa säkerhetskopian från före uppdateringen.

Den säkra återställningsgränsen för **Installation: Unraid** kräver dessa åtgärder innan något startas eller fortsätter: betan kan ändra databasen så att den stabila appen inte kan läsa den; peka den aldrig mot den stabila appens mappar; startprogrammet monterar Docker-socketen och styr därmed Docker på servern; installera det bara om du litar på dess avbildning; säkerhetskopian i appen (Administration → Backup, även schemalagd) flyttar ett bibliotek mellan Docker, Unraid och Home Assistant; startprogrammet skickar ännu inte vidare OpenID Connect-variablerna, så Unraid-mallen loggar in med passkeys eller lösenord.
