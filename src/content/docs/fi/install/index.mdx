## Tavoite ja tulos

Suorita sivukohtainen työnkulku: **Asennus: Asennusvaihtoehdot**. Tässä menettelyssä käytetään `:latest` · `:beta` · `:legacy` · `DISCVAULT_IMAGE` · PostgreSQL `/data` · `/update/migration/`.

## Koskee

Tämä sivu koskee vain kohdetta **Asennus: Asennusvaihtoehdot** (Docker · Unraid). Kanava- ja tietorajat ovat: DiscVault · `ghcr.io/helmerznl/discvault:latest`; `:beta`; PostgreSQL `17` `/data`; DiscVault · `ghcr.io/helmerznl/discvault:beta`; `:beta`; PostgreSQL `17` `/data`. Sivukohtaiset tarkistuspisteet: `:latest` · `:beta` · `:legacy` · `DISCVAULT_IMAGE` · PostgreSQL `/data` · `/update/migration/`.

### DiscVault – beta

## Toimenpiteet

1. **Valitse:** [Asennus: Docker Compose](/fi/install/docker-compose/) · DiscVault `main` `release/v26-beta`
2. **Valitse:** [Asennus: Docker run](/fi/install/docker-run/)
3. **Valitse:** [Asennus: Unraid](/fi/install/unraid/) · Unraid DiscVault
4. **Valitse:** [Asennus: Home Assistant](/fi/install/home-assistant/) · PostgreSQL 17
5. **Valitse:** uudet asennukset käyttävät DiscVault -tunnistetta `:latest` tai `:beta`; jäädytetty `:legacy`-image on vain olemassa olevalle edellisen sukupolven asennukselle, jota ei vielä siirretä
6. **Säilytä:** pidä edellisen sukupolven taltiot, ympäristömuuttujat, portit ja datapolku ennallaan; älä koskaan vaihda DiscVault PostgreSQL Compose -topologian imagea `:legacy`-imageksi
7. **Avaa:** [Päivitys ja siirto: Siirtyminen DiscVault:een](/fi/update/migration/) · → DiscVault
8. **Kirjaa:** `DISCVAULT_IMAGE` · vain olemassa olevalle tai legacy-käyttöönotolle: vastaava varmuuskopiosarja

## Turvallisuus ja palautus

:::caution
Turvallinen palautusraja kohteelle **Asennus: Asennusvaihtoehdot** edellyttää näitä toimia ennen käynnistystä tai jatkamista: Vain Legacy-haara: vaihda varmuuskopioinnin jälkeen vain nykyisen vanhan käyttöönoton image-tunnisteeksi `:legacy`, vedä ja luo se uudelleen topologiaa muuttamatta, tarkista kokoelma ja lopeta; älä vaihda tätä olemassa olevaa käyttöönottoa DiscVault-topologiaan tällä sivulla; jäädytetty `:legacy`-image ei saa DiscVault -ominaisuuksia, siirron parannuksia eikä tulevia käyttöliittymäpäivityksiä; vain olemassa olevalle tai legacy-käyttöönotolle: vastaava varmuuskopiosarja; julkaisutiedot ja kirjattu muuttumaton image-tiiviste. Sivukohtaiset tarkistuspisteet: `:latest` · `:beta` · `:legacy` · `DISCVAULT_IMAGE` · PostgreSQL `/data` · `/update/migration/`.
