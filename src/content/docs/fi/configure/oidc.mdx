Tämä sivu koskee vain kohdetta **Määritys: OpenID Connect (OIDC) -kirjautuminen** (Docker · verkko). Kanava- ja tietorajat ovat: DiscVault · `26.9.117+`; OIDC lisää valinnaisen selainkirjautumisen; paikalliset passkey-avaimet, valinnaiset salasanat, palautuskoodit, API-tokenit ja MCP bearer -tokenit säilyttävät nykyiset roolinsa; identiteetti on tarkka issuer- ja subject-pari; sähköpostia ei koskaan linkitetä automaattisesti, linkitys vaatii kirjautuneen selainistunnon ja linkityksen poisto toisen käyttökelpoisen kirjautumistavan. ## Edellytykset

- luottamuksellinen OIDC-asiakas identiteetintarjoajalla ja täsmällinen DiscVault-paluuosoite

:::note[Saatavilla betassa]

:::

## Toimenpiteet

1. **Luo:** luottamuksellinen OIDC-asiakas identiteetintarjoajalla ja täsmällinen DiscVault-paluuosoite · `openid profile email` · `https://discvault.example.com/api/next/auth/oidc/callback`
2. **Määritä:** `DISCVAULT_OIDC_ISSUER` · `DISCVAULT_OIDC_CLIENT_ID` · `DISCVAULT_OIDC_CLIENT_SECRET` · aseta myöntäjä, asiakastunnus ja asiakassalaisuus yhdessä tai jätä kaikki kolme tyhjiksi; osittainen määritys estää käynnistyksen
3. **Määritä:** `DISCVAULT_OIDC_PROVIDER_NAME` · `OIDC`
4. **Valitse:** `DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS` · `localhost` · Kubernetes DNS · `.internal` · salli tarkat yksityiset HTTP-origin-osoitteet vain token- ja JWKS-päätepisteille; issuer ja selainvaltuutus pysyvät vain HTTPS-yhteydessä, TLS-tarkistus säilyy käytössä ja discovery-, token- ja JWKS-uudelleenohjaukset estetään
5. **Käynnistä:** `next-api` · `--force-recreate`
6. **Testaa:** OIDC lisää valinnaisen selainkirjautumisen; paikalliset passkey-avaimet, valinnaiset salasanat, palautuskoodit, API-tokenit ja MCP bearer -tokenit säilyttävät nykyiset roolinsa · identiteetti on tarkka issuer- ja subject-pari; sähköpostia ei koskaan linkitetä automaattisesti, linkitys vaatii kirjautuneen selainistunnon ja linkityksen poisto toisen käyttökelpoisen kirjautumistavan
7. **Tarkista:** `auth.oidc_failed` · virheistä tallennetaan vain palveluntarjoajan määritetty näyttönimi, turvallinen `auth.oidc_failed`-koodi ja työnkulun tila; salaisuuksia, tokeneita, valtuutuskoodeja, state- tai nonce-arvoja, päätepisteiden URL-osoitteita ja PKCE-arvoja ei koskaan kirjata

### Komennot ja asetukset

#### DiscVault v26 – beta

```text
RP_ORIGINS=https://discvault.example.com
DISCVAULT_OIDC_ISSUER=https://id.example.com
DISCVAULT_OIDC_CLIENT_ID=<client-id>
DISCVAULT_OIDC_CLIENT_SECRET=<client-secret>
DISCVAULT_OIDC_PROVIDER_NAME=Pocket ID
DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS=
```

```text
DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS=http://pocket-id.pocket-id.svc.cluster.local:1411
```

```bash
cd /opt/discvault-next
docker compose -p discvault_next_deploy config --quiet
docker compose -p discvault_next_deploy up -d --force-recreate next-api
curl --fail https://discvault.example.com/api/next/auth/status
```
