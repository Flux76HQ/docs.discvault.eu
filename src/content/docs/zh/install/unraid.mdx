## 目标和结果

从 Unraid Community Applications 商店安装 DiscVault。该模板会安装 DiscVault 启动器，由它为你创建并更新 PostgreSQL、API、worker 和 MCP。.

完成此页面专用的流程： **安装: Unraid**. 此流程使用 `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## 适用范围

Helmer’s Repository 提供 DiscVault 和 DiscVault (beta) 两个模板，各自拥有独立的 appdata 文件夹、端口、Compose 项目和网络，可并行运行.

本页面仅适用于 **安装: Unraid** (Unraid). 通道与数据边界为： DiscVault · `ghcr.io/helmerznl/discvault-launcher:latest`; `6080` · `/mnt/user/appdata/discvault` · `discvault_stack`; DiscVault · `ghcr.io/helmerznl/discvault-launcher:beta`; `6081` · `/mnt/user/appdata/discvault-beta` · `discvault_beta_stack`. 本页面专用检查点： `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## 前提条件

- Unraid `6.12+`
- 已安装 Community Applications 插件
- 通行密钥需要在应用端口前提供带域名的 HTTPS 地址；没有时请使用带 TOTP 的密码登录

## 操作步骤

1. **打开:** Apps → 搜索 DiscVault → 安装；测试版模板的名称带有 (beta)
2. **配置:** 保留默认 appdata 文件夹；启动器文件夹保存生成的 Compose 文件和 `/config/stack.env` 中的密钥 · `TZ`
3. **配置:** `RP_ID` · `RP_ORIGINS` · 通行密钥需要在应用端口前提供带域名的 HTTPS 地址；没有时请使用带 TOTP 的密码登录 · `LEGACY_AUTH_ENABLED=true`
4. **启动:** 首次启动需要几分钟，启动器会拉取镜像并创建数据库 · 启动器会挂载 Docker socket，因而可以控制服务器上的 Docker；仅在信任启动器镜像时安装
5. **验证:** `/api/next/health` · 初始设置会用通行密钥或密码加 TOTP 创建第一位所有者，并只显示一次恢复代码
6. **配置:** Docker 选项卡 → 检查更新；启动时启动器也会更新堆栈的其余部分 · `DISCVAULT_CHANNEL=manual` · `DISCVAULT_IMAGE`

启动器已拉取镜像并创建堆栈，Web 界面在模板端口上响应，健康地址报告数据库已完成迁移.

## 安全与回滚

:::caution
复制三个 appdata 文件夹前先停止应用。若要回退，请将发布通道设为 manual 并填写上一版本标签，然后恢复更新前的备份。.

安全恢复边界： **安装: Unraid** 在启动或继续任何操作前必须执行： 测试版可能以稳定版无法读取的方式更改数据库；切勿让它指向稳定版的文件夹; 启动器会挂载 Docker socket，因而可以控制服务器上的 Docker；仅在信任启动器镜像时安装; 应用内备份（管理 → Backup，也可按计划运行）可在 Docker、Unraid 与 Home Assistant 之间迁移收藏库; 启动器尚未传递 OpenID Connect 变量，因此 Unraid 模板使用通行密钥或密码登录. 本页面专用检查点： `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

- 测试版可能以稳定版无法读取的方式更改数据库；切勿让它指向稳定版的文件夹
- 启动器会挂载 Docker socket，因而可以控制服务器上的 Docker；仅在信任启动器镜像时安装
- 应用内备份（管理 → Backup，也可按计划运行）可在 Docker、Unraid 与 Home Assistant 之间迁移收藏库
- 启动器尚未传递 OpenID Connect 变量，因此 Unraid 模板使用通行密钥或密码登录
:::
