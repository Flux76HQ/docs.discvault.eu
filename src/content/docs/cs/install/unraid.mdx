## Cíl a výsledek

Nainstalujte DiscVault z obchodu Unraid Community Applications. Šablona nainstaluje spouštěč DiscVault, který za vás vytvoří a aktualizuje PostgreSQL, API, worker a MCP.

Dokončete postup určený pro **Instalace: Unraid**. Tento postup pracuje s `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## Platí pro

Helmer’s Repository nabízí DiscVault a DiscVault (beta) jako dvě šablony, každou s vlastními složkami appdata, portem, projektem Compose a sítí, takže mohou běžet vedle sebe.

Tato stránka platí pouze pro **Instalace: Unraid** (Unraid). ## Požadavky

- Unraid `6.12+`
- nainstalovaný plugin Community Applications
- passkeys vyžadují adresu HTTPS s doménovým jménem před portem aplikace; bez ní použijte přihlášení heslem s TOTP

## Postup

1. **Otevřete:** Aplikace → vyhledejte DiscVault → Instalovat; šablona beta má v názvu (beta)
2. **Nastavte:** ponechte výchozí složky appdata; složka spouštěče obsahuje vygenerovaný soubor Compose a tajné hodnoty v `/config/stack.env` · `TZ`
3. **Nastavte:** `RP_ID` · `RP_ORIGINS` · passkeys vyžadují adresu HTTPS s doménovým jménem před portem aplikace; bez ní použijte přihlášení heslem s TOTP · `LEGACY_AUTH_ENABLED=true`
4. **Spusťte:** první spuštění trvá několik minut, než spouštěč stáhne obrazy a vytvoří databázi · spouštěč připojuje Docker socket, a tím ovládá Docker na serveru; instalujte jej jen tehdy, když obrazu spouštěče důvěřujete
5. **Ověřte:** `/api/next/health` · úvodní nastavení vytvoří prvního vlastníka s passkey nebo s heslem a TOTP a jednou zobrazí obnovovací kódy
6. **Nastavte:** karta Docker → Zkontrolovat aktualizace; při spuštění spouštěč aktualizuje i zbytek stacku · `DISCVAULT_CHANNEL=manual` · `DISCVAULT_IMAGE`
