## Διαδικασία

1. **Δημιουργήστε:** ένας εμπιστευτικός πελάτης OIDC στον πάροχο ταυτότητας με το ακριβές URI επιστροφής του DiscVault · `openid profile email` · `https://discvault.example.com/api/next/auth/oidc/callback`
2. **Ρυθμίστε:** `DISCVAULT_OIDC_ISSUER` · `DISCVAULT_OIDC_CLIENT_ID` · `DISCVAULT_OIDC_CLIENT_SECRET` · ορίστε μαζί εκδότη, αναγνωριστικό πελάτη και μυστικό πελάτη ή αφήστε και τα τρία κενά· η μερική ρύθμιση εμποδίζει την εκκίνηση
3. **Ρυθμίστε:** `DISCVAULT_OIDC_PROVIDER_NAME` · `OIDC`
4. **Επιλέξτε:** `DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS` · `localhost` · Kubernetes DNS · `.internal` · επιτρέψτε ακριβή ιδιωτικά HTTP origins μόνο για endpoints token και JWKS· ο issuer και η εξουσιοδότηση του προγράμματος περιήγησης παραμένουν μόνο HTTPS, η επαλήθευση TLS παραμένει ενεργή και οι ανακατευθύνσεις discovery, token και JWKS απορρίπτονται
5. **Εκκινήστε:** `next-api` · `--force-recreate`
6. **Δοκιμάστε:** Το OIDC προσθέτει προαιρετική σύνδεση μέσω προγράμματος περιήγησης· τα τοπικά passkeys, οι προαιρετικοί κωδικοί πρόσβασης, οι κωδικοί ανάκτησης, τα API tokens και τα MCP bearer tokens διατηρούν τους ρόλους τους · μια ταυτότητα είναι το ακριβές ζεύγος issuer και subject· το email δεν συνδέεται ποτέ αυτόματα, η σύνδεση απαιτεί την ενεργή συνεδρία του προγράμματος περιήγησης και η αποσύνδεση απαιτεί άλλη χρησιμοποιήσιμη μέθοδο εισόδου
7. **Ελέγξτε:** `auth.oidc_failed` · οι αποτυχίες καταγράφουν μόνο το ρυθμισμένο εμφανιζόμενο όνομα παρόχου, ασφαλή κωδικό `auth.oidc_failed` και λειτουργία ροής· μυστικά, tokens, κωδικοί εξουσιοδότησης, state, nonce, URL endpoints και τιμές PKCE δεν καταγράφονται ποτέ

### Εντολές και ρυθμίσεις

#### DiscVault v26 – beta

```text
RP_ORIGINS=https://discvault.example.com
DISCVAULT_OIDC_ISSUER=https://id.example.com
DISCVAULT_OIDC_CLIENT_ID=<client-id>
DISCVAULT_OIDC_CLIENT_SECRET=<client-secret>
DISCVAULT_OIDC_PROVIDER_NAME=Pocket ID
DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS=
```

```text
DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS=http://pocket-id.pocket-id.svc.cluster.local:1411
```

```bash
cd /opt/discvault-next
docker compose -p discvault_next_deploy config --quiet
docker compose -p discvault_next_deploy up -d --force-recreate next-api
curl --fail https://discvault.example.com/api/next/auth/status
```
