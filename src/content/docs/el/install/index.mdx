6. **Διατηρήστε:** διατηρήστε αμετάβλητα τα volumes, τις μεταβλητές περιβάλλοντος, τις θύρες και τη διαδρομή δεδομένων της προηγούμενης γενιάς· μην αντικαθιστάτε ποτέ εικόνα στην τοπολογία DiscVault PostgreSQL Compose με `:legacy`
7. **Ανοίξτε:** [Ενημέρωση και μετεγκατάσταση: Μετεγκατάσταση στο DiscVault](/el/update/migration/) · → DiscVault
8. **Καταγράψτε:** `DISCVAULT_IMAGE` · μόνο για υπάρχουσα ή legacy ανάπτυξη: αντίστοιχο σύνολο αντιγράφων
