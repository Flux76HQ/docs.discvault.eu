## Prosedür

1. **Oluşturun:** kimlik sağlayıcısında tam DiscVault geri çağırma URI değerine sahip gizli bir OIDC istemcisi · `openid profile email` · `https://discvault.example.com/api/next/auth/oidc/callback`
2. **Yapılandırın:** `DISCVAULT_OIDC_ISSUER` · `DISCVAULT_OIDC_CLIENT_ID` · `DISCVAULT_OIDC_CLIENT_SECRET` · issuer, istemci kimliği ve istemci gizlisini birlikte ayarlayın veya üçünü de boş bırakın; kısmi yapılandırma başlatmayı engeller
3. **Yapılandırın:** `DISCVAULT_OIDC_PROVIDER_NAME` · `OIDC`
4. **Seçin:** `DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS` · `localhost` · Kubernetes DNS · `.internal` · tam özel HTTP originlerine yalnızca token ve JWKS uç noktaları için izin verin; issuer ve tarayıcı yetkilendirmesi yalnızca HTTPS olarak kalır, TLS doğrulaması etkin kalır ve discovery, token ve JWKS yönlendirmeleri reddedilir
5. **Başlatın:** `next-api` · `--force-recreate`
6. **Test edin:** OIDC isteğe bağlı bir tarayıcı oturum açma yöntemi ekler; yerel passkey, isteğe bağlı parolalar, kurtarma kodları, API belirteçleri ve MCP bearer belirteçleri mevcut rollerini korur · bir kimlik tam issuer ve subject çiftidir; e-posta hiçbir zaman otomatik bağlanmaz, bağlama oturum açılmış tarayıcı oturumu gerektirir ve bağlantıyı kaldırmak için başka bir kullanılabilir giriş yöntemi gerekir
7. **İnceleyin:** `auth.oidc_failed` · hatalar yalnızca sağlayıcının yapılandırılmış görünen adını, güvenli bir `auth.oidc_failed` kodunu ve akış modunu kaydeder; gizli bilgiler, belirteçler, yetkilendirme kodları, state, nonce, uç nokta URL’leri ve PKCE değerleri asla günlüğe yazılmaz

### Komutlar ve ayarlar

#### DiscVault v26 beta

```text
RP_ORIGINS=https://discvault.example.com
DISCVAULT_OIDC_ISSUER=https://id.example.com
DISCVAULT_OIDC_CLIENT_ID=<client-id>
DISCVAULT_OIDC_CLIENT_SECRET=<client-secret>
DISCVAULT_OIDC_PROVIDER_NAME=Pocket ID
DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS=
```

```text
DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS=http://pocket-id.pocket-id.svc.cluster.local:1411
```

```bash
cd /opt/discvault-next
docker compose -p discvault_next_deploy config --quiet
docker compose -p discvault_next_deploy up -d --force-recreate next-api
curl --fail https://discvault.example.com/api/next/auth/status
```
