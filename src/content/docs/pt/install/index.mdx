## Procedimento

1. **Escolher:** [Instalação: Docker Compose](/pt/install/docker-compose/) · DiscVault
2. **Escolher:** [Instalação: Docker run](/pt/install/docker-run/)
3. **Escolher:** [Instalação: Unraid](/pt/install/unraid/) · Unraid DiscVault
4. **Escolher:** [Instalação: Home Assistant](/pt/install/home-assistant/) · PostgreSQL 17
5. **Escolher:** as novas instalações usam DiscVault `:latest` ou `:beta`; a imagem congelada `:legacy` destina-se apenas a uma instalação existente da geração anterior que ainda não esteja pronta para migrar
6. **Preservar:** mantenha inalterados os volumes, variáveis de ambiente, portas e caminho de dados da geração anterior; nunca substitua uma imagem na topologia Compose DiscVault PostgreSQL por `:legacy`
7. **Abrir:** [Atualização e migração: Migração para DiscVault](/pt/update/migration/) · → DiscVault
8. **Registar:** `DISCVAULT_IMAGE` · apenas para uma implementação existente ou legacy: conjunto de cópias correspondente
