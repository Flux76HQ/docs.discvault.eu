## Procedura

1. **Scegli:** [Installazione: Docker Compose](/it/install/docker-compose/) · DiscVault
2. **Scegli:** [Installazione: Docker run](/it/install/docker-run/)
3. **Scegli:** [Installazione: Unraid](/it/install/unraid/) · Unraid DiscVault
4. **Scegli:** [Installazione: Home Assistant](/it/install/home-assistant/) · PostgreSQL 17
5. **Scegli:** le nuove installazioni usano DiscVault `:latest` o `:beta`; l’immagine congelata `:legacy` è solo per un’installazione esistente della generazione precedente non ancora pronta alla migrazione
6. **Conserva:** mantieni invariati volumi, variabili d’ambiente, porte e percorso dati della generazione precedente; non sostituire mai un’immagine nella topologia Compose DiscVault PostgreSQL con `:legacy`
7. **Apri:** [Aggiornamento e migrazione: Migrazione a DiscVault](/it/update/migration/) · → DiscVault
8. **Registra:** `DISCVAULT_IMAGE` · solo per un deployment esistente o legacy: set di backup corrispondente
