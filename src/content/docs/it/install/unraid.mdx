## Obiettivo e risultato

Installa DiscVault dallo store Community Applications di Unraid. Il modello installa il launcher DiscVault, che crea e aggiorna per te PostgreSQL, l’API, il worker e MCP.

Completa la procedura specifica della pagina per **Installazione: Unraid**. Questa procedura utilizza `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## Si applica a

Helmer’s Repository offre DiscVault e DiscVault (beta) come due modelli, ciascuno con cartelle appdata, porta, progetto Compose e rete propri, così funzionano affiancati.

Questa pagina si applica solo a **Installazione: Unraid** (Unraid). I limiti di canale e dati sono: DiscVault · `ghcr.io/helmerznl/discvault-launcher:latest`; `6080` · `/mnt/user/appdata/discvault` · `discvault_stack`; DiscVault · `ghcr.io/helmerznl/discvault-launcher:beta`; `6081` · `/mnt/user/appdata/discvault-beta` · `discvault_beta_stack`. Punti di controllo della pagina: `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## Prerequisiti

- Unraid `6.12+`
- plugin Community Applications installato
- le passkey richiedono un indirizzo HTTPS con nome di dominio davanti alla porta dell’app; senza, usa l’accesso con password e TOTP

## Procedura

1. **Apri:** Apps → cerca DiscVault → Installa; il modello beta ha (beta) nel nome
2. **Configura:** mantieni le cartelle appdata predefinite; la cartella del launcher contiene il file Compose generato e i segreti in `/config/stack.env` · `TZ`
3. **Configura:** `RP_ID` · `RP_ORIGINS` · le passkey richiedono un indirizzo HTTPS con nome di dominio davanti alla porta dell’app; senza, usa l’accesso con password e TOTP · `LEGACY_AUTH_ENABLED=true`
4. **Avvia:** il primo avvio richiede qualche minuto mentre il launcher scarica le immagini e crea il database · il launcher monta il socket Docker e quindi controlla Docker sul server; installalo solo se ti fidi della sua immagine
5. **Verifica:** `/api/next/health` · l’onboarding crea il primo proprietario con una passkey, oppure con password e TOTP, e mostra una sola volta i codici di recupero
6. **Configura:** scheda Docker → Controlla aggiornamenti; all’avvio il launcher aggiorna anche il resto dello stack · `DISCVAULT_CHANNEL=manual` · `DISCVAULT_IMAGE`

## Sicurezza e ripristino

:::caution
Arresta l’app prima di copiare le sue tre cartelle appdata. Per tornare indietro imposta il canale su manual con il tag della versione precedente e ripristina il backup fatto prima dell’aggiornamento.

Il limite di ripristino sicuro per **Installazione: Unraid** richiede queste azioni prima di avviare o continuare: la beta può modificare il database in modo che l’app stabile non riesca a leggerlo; non puntarla mai alle cartelle della stabile; il launcher monta il socket Docker e quindi controlla Docker sul server; installalo solo se ti fidi della sua immagine; il backup nell’app (Amministrazione → Backup, anche pianificato) sposta una libreria tra Docker, Unraid e Home Assistant; il launcher non trasmette ancora le variabili OpenID Connect, quindi il modello Unraid accede con passkey o password.
