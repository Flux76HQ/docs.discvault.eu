## Процедура

1. **Виберіть:** [Встановлення: Docker Compose](/uk/install/docker-compose/) · DiscVault `main` `release/v26-beta`
2. **Виберіть:** [Встановлення: Docker run](/uk/install/docker-run/)
3. **Виберіть:** [Встановлення: Unraid](/uk/install/unraid/) · Unraid DiscVault
4. **Виберіть:** [Встановлення: Home Assistant](/uk/install/home-assistant/) · PostgreSQL 17
5. **Виберіть:** нові інсталяції використовують DiscVault `:latest` або `:beta`; заморожений образ `:legacy` призначений лише для наявної інсталяції попереднього покоління, яка ще не готова до міграції
6. **Збережіть:** залиште без змін томи, змінні середовища, порти та шлях даних попереднього покоління; ніколи не підставляйте `:legacy` у топологію DiscVault PostgreSQL Compose
7. **Відкрийте:** [Оновлення й міграція: Міграція до DiscVault](/uk/update/migration/) · → DiscVault
8. **Запишіть:** `DISCVAULT_IMAGE` · лише для наявного або legacy розгортання: відповідний комплект резервних копій
