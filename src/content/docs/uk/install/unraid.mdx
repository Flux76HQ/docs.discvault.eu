## Мета й результат

Установіть DiscVault з магазину Unraid Community Applications. Шаблон встановлює запускач DiscVault, який створює й оновлює для вас PostgreSQL, API, worker і MCP.

Виконайте спеціальну процедуру сторінки для **Встановлення: Unraid**. У цій процедурі використовуються `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## Застосовується до

Helmer’s Repository пропонує DiscVault і DiscVault (beta) як два шаблони з власними теками appdata, портом, проєктом Compose і мережею, тож вони працюють паралельно.

Ця сторінка стосується лише **Встановлення: Unraid** (Unraid). Межі каналу й даних: DiscVault · `ghcr.io/helmerznl/discvault-launcher:latest`; `6080` · `/mnt/user/appdata/discvault` · `discvault_stack`; DiscVault · `ghcr.io/helmerznl/discvault-launcher:beta`; `6081` · `/mnt/user/appdata/discvault-beta` · `discvault_beta_stack`. Контрольні точки цієї сторінки: `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## Передумови

- Unraid `6.12+`
- встановлений плагін Community Applications
- passkeys потребують HTTPS-адреси з доменним ім’ям перед портом застосунку; без неї використовуйте вхід за паролем із TOTP

## Процедура

1. **Відкрийте:** Apps → знайдіть DiscVault → Установити; бета-шаблон має (beta) у назві
2. **Налаштуйте:** залиште стандартні теки appdata; тека запускача містить згенерований файл Compose і секрети в `/config/stack.env` · `TZ`
3. **Налаштуйте:** `RP_ID` · `RP_ORIGINS` · passkeys потребують HTTPS-адреси з доменним ім’ям перед портом застосунку; без неї використовуйте вхід за паролем із TOTP · `LEGACY_AUTH_ENABLED=true`
4. **Запустіть:** перший запуск триває кілька хвилин, поки запускач завантажує образи й створює базу даних · запускач монтує сокет Docker і тому керує Docker на сервері; встановлюйте його, лише якщо довіряєте образу запускача
5. **Перевірте:** `/api/next/health` · початкове налаштування створює першого власника з passkey або з паролем і TOTP та один раз показує коди відновлення
6. **Налаштуйте:** вкладка Docker → Перевірити оновлення; під час запуску запускач оновлює й решту стека · `DISCVAULT_CHANNEL=manual` · `DISCVAULT_IMAGE`
