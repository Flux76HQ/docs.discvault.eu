## 目的と結果

Unraid の Community Applications ストアから DiscVault をインストールします。テンプレートは DiscVault ランチャーを導入し、PostgreSQL、API、ワーカー、MCP を作成・更新します。.

このページ専用の手順を実行します: **インストール: Unraid**. この手順で扱う項目: `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## 対象

Helmer’s Repository は DiscVault と DiscVault (beta) の 2 つのテンプレートを提供し、それぞれ専用の appdata フォルダー、ポート、Compose プロジェクト、ネットワークを持つため並行して動作します.

このページの対象は **インストール: Unraid** (Unraid). チャンネルとデータの境界: DiscVault · `ghcr.io/helmerznl/discvault-launcher:latest`; `6080` · `/mnt/user/appdata/discvault` · `discvault_stack`; DiscVault · `ghcr.io/helmerznl/discvault-launcher:beta`; `6081` · `/mnt/user/appdata/discvault-beta` · `discvault_beta_stack`. このページ固有の確認点: `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## 前提条件

- Unraid `6.12+`
- Community Applications プラグインがインストール済み
- パスキーにはアプリのポートの前にドメイン名付きの HTTPS アドレスが必要です。ない場合は TOTP 付きのパスワードログインを使います

## 手順

1. **開く:** Apps → DiscVault を検索 → インストール。ベータ版テンプレートは名前に (beta) が付きます
2. **設定:** 既定の appdata フォルダーを使います。ランチャーのフォルダーには生成された Compose ファイルと `/config/stack.env` のシークレットが入ります · `TZ`
3. **設定:** `RP_ID` · `RP_ORIGINS` · パスキーにはアプリのポートの前にドメイン名付きの HTTPS アドレスが必要です。ない場合は TOTP 付きのパスワードログインを使います · `LEGACY_AUTH_ENABLED=true`
4. **開始:** 初回起動では、ランチャーがイメージを取得してデータベースを作成するため数分かかります · ランチャーは Docker ソケットをマウントするため、サーバーの Docker を操作できます。ランチャーのイメージを信頼できる場合のみインストールしてください
5. **検証:** `/api/next/health` · オンボーディングでパスキー、またはパスワードと TOTP で最初のオーナーを作成し、復旧コードを一度だけ表示します
6. **設定:** Docker タブ → 更新を確認。起動時にランチャーがスタックの残りも更新します · `DISCVAULT_CHANNEL=manual` · `DISCVAULT_IMAGE`

## 安全性とロールバック

:::caution
3 つの appdata フォルダーをコピーする前にアプリを停止します。戻すときはリリースチャネルを manual にして前のバージョンタグを指定し、更新前のバックアップを復元します。.

安全な復旧境界: **インストール: Unraid** 起動または続行の前に、次の操作が必要です: ベータは安定版が読めない形でデータベースを変更することがあります。安定版のフォルダーを指定しないでください; ランチャーは Docker ソケットをマウントするため、サーバーの Docker を操作できます。ランチャーのイメージを信頼できる場合のみインストールしてください; アプリ内バックアップ（管理 → Backup、スケジュール実行も可）でライブラリを Docker、Unraid、Home Assistant 間で移行できます; ランチャーはまだ OpenID Connect の変数を渡さないため、Unraid テンプレートはパスキーまたはパスワードでログインします. このページ固有の確認点: `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

- ベータは安定版が読めない形でデータベースを変更することがあります。安定版のフォルダーを指定しないでください
- ランチャーは Docker ソケットをマウントするため、サーバーの Docker を操作できます。ランチャーのイメージを信頼できる場合のみインストールしてください
- アプリ内バックアップ（管理 → Backup、スケジュール実行も可）でライブラリを Docker、Unraid、Home Assistant 間で移行できます
- ランチャーはまだ OpenID Connect の変数を渡さないため、Unraid テンプレートはパスキーまたはパスワードでログインします
:::
