## Fremgangsmåte

1. **Opprett:** en konfidensiell OIDC-klient hos identitetsleverandøren med nøyaktig DiscVault-tilbakekallings-URI · `openid profile email` · `https://discvault.example.com/api/next/auth/oidc/callback`
2. **Konfigurer:** `DISCVAULT_OIDC_ISSUER` · `DISCVAULT_OIDC_CLIENT_ID` · `DISCVAULT_OIDC_CLIENT_SECRET` · angi utsteder, klient-ID og klienthemmelighet samlet, eller la alle tre stå tomme; en delvis konfigurasjon hindrer oppstart
3. **Konfigurer:** `DISCVAULT_OIDC_PROVIDER_NAME` · `OIDC`
4. **Velg:** `DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS` · `localhost` · Kubernetes DNS · `.internal` · tillat bare eksakte private HTTP-opprinnelser for token- og JWKS-endepunkter; utsteder og nettleserautorisasjon forblir HTTPS-only, TLS-kontroll forblir aktiv, og discovery-, token- og JWKS-omdirigeringer avvises
5. **Start:** `next-api` · `--force-recreate`
6. **Test:** OIDC legger til en valgfri pålogging i nettleseren; lokale passkeys, valgfrie passord, gjenopprettingskoder, API-tokener og MCP bearer-tokener beholder rollene sine · en identitet er det eksakte paret issuer og subject; e-post kobles aldri automatisk, kobling krever den påloggede nettleserøkten, og frakobling krever en annen brukbar påloggingsmetode
7. **Kontroller:** `auth.oidc_failed` · feil registrerer bare leverandørens konfigurerte visningsnavn, en trygg `auth.oidc_failed`-kode og flytmodus; hemmeligheter, tokener, autorisasjonskoder, state, nonce, endepunkt-URL-er og PKCE-verdier logges aldri

### Kommandoer og innstillinger

#### DiscVault v26 – beta

```text
RP_ORIGINS=https://discvault.example.com
DISCVAULT_OIDC_ISSUER=https://id.example.com
DISCVAULT_OIDC_CLIENT_ID=<client-id>
DISCVAULT_OIDC_CLIENT_SECRET=<client-secret>
DISCVAULT_OIDC_PROVIDER_NAME=Pocket ID
DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS=
```

```text
DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS=http://pocket-id.pocket-id.svc.cluster.local:1411
```

```bash
cd /opt/discvault-next

docker compose -p discvault_next_deploy up -d --force-recreate next-api
curl --fail https://discvault.example.com/api/next/auth/status
```
