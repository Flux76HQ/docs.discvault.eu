## Mål og resultat

Installer DiscVault fra Unraid-butikken Community Applications. Malen installerer DiscVault-launcheren, som oppretter og oppdaterer PostgreSQL, API, worker og MCP for deg.

Fullfør den sidespesifikke arbeidsflyten for **Installasjon: Unraid**. Denne fremgangsmåten bruker `ghcr.io/helmerznl/discvault-launcher:latest` · `/var/run/docker.sock` · `/api/next/health`.

## Fremgangsmåte

1. **Åpne:** Apps → søk etter DiscVault → Installer; betamalen har (beta) i navnet
2. **Konfigurer:** behold standardmappene i appdata; launcher-mappen inneholder den genererte Compose-filen og hemmelighetene i `/config/stack.env` · `TZ`
3. **Konfigurer:** `RP_ID` · `RP_ORIGINS` · passkeys krever en HTTPS-adresse med domenenavn foran appens port; uten det bruker du passordpålogging med TOTP · `LEGACY_AUTH_ENABLED=true`
4. **Start:** første oppstart tar noen minutter mens launcheren henter imagene og oppretter databasen · launcheren monterer Docker-socketen og styrer dermed Docker på serveren; installer den bare hvis du stoler på launcher-imaget
5. **Bekreft:** `/api/next/health` · introduksjonen oppretter den første eieren med passkey, eller med passord og TOTP, og viser gjenopprettingskodene én gang
6. **Konfigurer:** fanen Docker → Se etter oppdateringer; ved oppstart oppdaterer launcheren også resten av stakken · `DISCVAULT_CHANNEL=manual` · `DISCVAULT_IMAGE`

## Sikkerhet og tilbakerulling

:::caution
Stopp appen før du kopierer de tre appdata-mappene. Rull tilbake ved å sette utgivelseskanalen til manual med forrige versjonstagg og gjenopprette sikkerhetskopien fra før oppdateringen.

Den sikre gjenopprettingsgrensen for **Installasjon: Unraid** krever disse handlingene før noe startes eller fortsetter: betaen kan endre databasen slik at den stabile appen ikke kan lese den; pek den aldri mot den stabile appens mapper; launcheren monterer Docker-socketen og styrer dermed Docker på serveren; installer den bare hvis du stoler på launcher-imaget; sikkerhetskopien i appen (Administrasjon → Backup, også etter tidsplan) flytter et bibliotek mellom Docker, Unraid og Home Assistant; launcheren sender ennå ikke OpenID Connect-variablene videre, så Unraid-malen logger på med passkeys eller passord.
