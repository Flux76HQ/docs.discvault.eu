## Eljárás

1. **Hozza létre:** bizalmas OIDC-kliens az identitásszolgáltatónál a pontos DiscVault visszahívási URI-val · `openid profile email` · `https://discvault.example.com/api/next/auth/oidc/callback`
2. **Állítsa be:** `DISCVAULT_OIDC_ISSUER` · `DISCVAULT_OIDC_CLIENT_ID` · `DISCVAULT_OIDC_CLIENT_SECRET` · a kibocsátót, ügyfélazonosítót és ügyféltitkot együtt állítsa be, vagy mindhármat hagyja üresen; a részleges beállítás megakadályozza az indulást
3. **Állítsa be:** `DISCVAULT_OIDC_PROVIDER_NAME` · `OIDC`
4. **Válassza ki:** `DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS` · `localhost` · Kubernetes DNS · `.internal` · pontos privát HTTP origin csak token- és JWKS-végpontokhoz engedélyezhető; a kibocsátó és a böngészős engedélyezés kizárólag HTTPS marad, a TLS-ellenőrzés aktív, a discovery-, token- és JWKS-átirányítások tiltottak
5. **Indítsa el:** `next-api` · `--force-recreate`
6. **Tesztelje:** Az OIDC választható böngészős bejelentkezést ad; a helyi passkey-k, választható jelszavak, helyreállítási kódok, API-tokenek és MCP bearer tokenek megtartják szerepüket · az identitás az issuer és subject pontos párja; az e-mail soha nem kapcsolódik automatikusan, a kapcsoláshoz bejelentkezett böngészős munkamenet, a leválasztáshoz pedig másik használható bejelentkezési mód kell
7. **Ellenőrizze:** `auth.oidc_failed` · a hibák csak a szolgáltató beállított megjelenítési nevét, biztonságos `auth.oidc_failed` kódot és folyamatmódot rögzítenek; titkok, tokenek, engedélyezési kódok, state, nonce, végpont-URL-ek és PKCE-értékek soha nem kerülnek naplóba

### Parancsok és beállítások

#### DiscVault v26 – béta

```text
RP_ORIGINS=https://discvault.example.com
DISCVAULT_OIDC_ISSUER=https://id.example.com
DISCVAULT_OIDC_CLIENT_ID=<client-id>
DISCVAULT_OIDC_CLIENT_SECRET=<client-secret>
DISCVAULT_OIDC_PROVIDER_NAME=Pocket ID
DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS=
```

```text
DISCVAULT_OIDC_INSECURE_BACKCHANNEL_ORIGINS=http://pocket-id.pocket-id.svc.cluster.local:1411
```

```bash
cd /opt/discvault-next
docker compose -p discvault_next_deploy config --quiet
docker compose -p discvault_next_deploy up -d --force-recreate next-api
curl --fail https://discvault.example.com/api/next/auth/status
```
